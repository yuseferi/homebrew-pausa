# Homebrew Tap for Pausa

A native macOS break reminder that pauses during meetings and media and takes
over every screen when it's time to rest.

```bash
brew install --cask yuseferi/pausa/pausa
```

**This repository is generated.** The canonical cask lives in
[`yuseferi/pausa`](https://github.com/yuseferi/pausa/blob/main/Casks/pausa.rb)
and is mirrored here automatically on each release. Please open issues and pull
requests in the main repository.
